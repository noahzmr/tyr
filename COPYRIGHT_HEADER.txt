--------------------------------------------------------------------------------
USAGE RULES
--------------------------------------------------------------------------------

1. Every NEW source file includes the header before its first
   declaration, in the language-appropriate comment form above. In Go
   the header block precedes the `// Package ...` doc comment.

2. Files that existed before 2026-11-18 have no header yet. They are
   covered by the LICENSE file all the same; adding headers to them is
   a separate, deliberate change.

3. The "Created" field is set once, when the file is first added to the
   repository, and never changed. The "Updated" field is bumped on
   substantive edits - typo fixes, formatting passes, and dependency
   bumps do not require it.

4. The SPDX-License-Identifier line is mandatory - automated tooling
   relies on it.

5. Do not remove copyright headers from contributed source files. This
   is required by MPL-2.0 Section 3.4.

6. Third-party files copied into the repository keep their original
   headers. Do not replace an upstream header with this one.

7. Generated files and test data carry no header: the recorded and
   synthetic hosts under testdata/fixtures/, golden files (testdata/
   golden/, *.golden), and the generated diagrams and images under
   docs/. They are data, not source.
